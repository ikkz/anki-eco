# 原生填空

::: warning 测试阶段
该模板目前处于 Beta 阶段。如果遇到任何问题，请到 [GitHub Issues](https://github.com/ikkz/anki-eco/issues) 反馈。
:::

直接使用 Anki 内置的填空语法，无需格式转换。

将需要挖空的文本用 <span v-pre>`{{c1::文本}}`</span> 包裹即可。每个填空编号会生成一张独立的卡片，其余文本保持可见作为上下文。

---

[[toc]]

## 快速上手

在 `question` 字段中书写填空：

<span v-pre>`中国的首都是 {{c1::北京}}，最大的城市是 {{c2::上海}}。`</span>

这会生成两张卡片：

- **卡片 1** — 隐藏所有 `c1` 填空；`c2` 的文本保持可见。
- **卡片 2** — 隐藏所有 `c2` 填空；`c1` 的文本保持可见。

复习时，点击灰色填空块或按 `W` 逐个显示答案，按 `Shift` + `Space` 可一次显示或隐藏全部填空。

## 提示功能

可以在第三段添加提示：<span v-pre>`{{c1::答案::提示}}`</span>。

隐藏的填空处会显示一个黄色提示块。桌面端悬停、移动端点击即可查看提示内容，答案仍保持隐藏，需要点击才能揭晓。

## 字段

| 字段     | 说明                             |
| -------- | -------------------------------- |
| question | 题目文本，在此处书写填空语法。   |
| answer   | 补充答案内容（显示在卡片背面）。 |
| note     | 额外的笔记、解析或参考资料。     |

## 与交互式填空的区别

该模板使用**独立的笔记类型**，不会影响现有的[交互式填空模板](/zh/templates/classic/cloze)。

|                  | 原生填空                                 | 交互式填空                   |
| ---------------- | ---------------------------------------- | ---------------------------- |
| 语法             | Anki 的 <span v-pre>`{{c1::...}}`</span> | <span v-pre>`{{...}}`</span> |
| 每条笔记的卡片数 | 每个填空编号一张卡片                     | 单张卡片                     |
| 图片 / 公式填空  | 不支持                                   | 支持                         |
